# Brupolo Store

Proyecto de tienda online desarrollado con React como parte del curso de Front End.

## Funcionalidades

* Listado de productos obtenido desde un archivo JSON.
* Vista individual con el detalle de cada producto.
* Navegación entre inicio, detalle y carrito.
* Manejo de estados de carga y errores.
* Diseño adaptable a diferentes tamaños de pantalla.

## Tecnologías utilizadas

* React
* Vite
* React Router DOM
* JavaScript
* CSS

## Instalación

Para instalar las dependencias:

```bash
npm install
```

Para iniciar el proyecto:

```bash
npm run dev
```
